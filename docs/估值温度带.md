# 估值温度带

更新：2026-11-03。

概览页「回本链」下方的市场参考卡：当前股票的**股价 / PE-TTM / PB-MRQ** 在近 5 年里的百分位温度带，辅助网格买卖决策（低温区适合分批买、高温区适合分批卖）。纯展示——不进台账、不参与任何计算与守恒式，快照数据也不进备份。

## 数据来源与刷新

- 静态快照 `src/domain/valuationData.json`，由 `scripts/fetchValuation.mjs` 抓取东方财富两个公开接口生成：日 K 线（前复权收盘）+ 每日估值（PE-TTM / PB-MRQ），按交易日对齐合并，收盘价存整数分。
- 刷新命令：`npm run refresh-valuation`。**什么时候必须刷新**：个股除权除息之后（前复权整条序列会重定基，不刷新则「昨收 vs 快照收盘」的缩放估算与百分位都失真）；想滚动 5 年窗口时。
- 快照随 PWA 预缓存、离线可用；卡片副标题展示「数据截至」，据此判断新鲜度。
- 覆盖股票 = 脚本里的 `STOCKS` 清单（柳工 / 三一重工 / 奥佳华 / 安道麦），**应用内股票名 ↔ 交易所代码**的映射也维护在那里（注意应用内叫「安道麦」，交易所简称是「安道麦A」）；要给新股票加温度带就改清单重跑。

## 百分位口径

- 窗口 = 快照内全部交易日（约 5 年、1200+ 个交易日）。
- **股价百分位** = 「收盘 < 现价」的天数占比（**严格小于**）。收盘为前复权价，序列今日点就是真实价，所以直接拿昨收比较成立。
- 现价取挂单页已确认的昨收；未确认时回退快照最后收盘，副标题会注明「按快照收盘」。
- **PE/PB 现值** = 快照最后一天的值 ×（现价 / 快照最后收盘）——EPS/BPS 在两次刷新之间不变的假设。
- PE/PB 百分位只在「**正值基准**」上算：亏损期 PE 为负没有比较意义（安道麦近 5 年 765 天亏损、奥佳华近期转亏）。
- 快照最后一天 PE/PB 非正 → 该指标显示「亏损 · 失效」不画针；此时以股价百分位与 PB 为主要参考（PB 同样受净资产变动影响，仅作参考、别当精确锚）。

## 分区与操作含义

| 温度 | 分区 | 网格含义 |
| --- | --- | --- |
| 0–20 | 极冷·低位 | 5 年低位区，适合分批建仓 / 加大买档 |
| 20–40 | 偏冷·低位 | 逢低吸纳，买档正常维持 |
| 40–60 | 中性 | 网格常态，按既有买卖档运行 |
| 60–80 | 偏热·高位 | 减少买入，卖档可上移分批兑现 |
| 80–100 | 过热·高位 | 重点减仓区，严控新开仓 |

- 周期股注意：低 PE 常出现在盈利景气顶点（盈利分母大），**低 PE ≠ 便宜**，要结合 PB 与股价位置一起看；反过来，高 PB 若来自净资产缩水（亏损股），也不是「过热」信号。
- 温度带只回答「位置」，不预测方向：极冷可以更冷（基本面恶化），过热可以更热。配合网格的既有买卖档使用，不单独构成买卖指令。
