# 版本检查与更新

更新：2026-11-04。适用于网页、添加到主屏幕的独立应用；不改变交易记账口径。

## 安装应用

管理首页顶部提供显式「安装应用」按钮。浏览器提供直接安装能力时，点击即可打开确认窗口；页面会从应用启动时接收安装事件，不必等待浏览器主动弹出横幅，也不必一直停在管理页。

若没有直接安装窗口，按钮会展开当前设备的安装方法：

- iPhone/iPad：浏览器分享菜单 → 添加到主屏幕 → 开启「作为网页 App 打开」（如出现）→ 添加。Safari部分布局需先点页面菜单再点分享；未见添加项可在编辑操作中补入。也可以在Safari打开本站后操作，不表示其它iOS浏览器都不能添加。
- 安卓：浏览器菜单 → 安装应用、安装并创建快捷方式或添加到主屏幕 → 确认。
- 电脑Chrome/Edge：使用地址栏的安装图标，或从浏览器菜单的分享/应用栏目安装；具体名称随版本不同，卡片列出参考路径。
- Mac Safari（macOS 14及以后）：文件或分享菜单 → 添加到程序坞。
- 微信等内置浏览器：先在外部浏览器打开本站；卡片内提供可选中复制的网站地址。

取消、失败和浏览器暂未提供安装窗口时，人工指引仍可使用；系统限制不能由网页按钮绕过。「已确认安装」只表示用户接受了提示，收到安装完成事件或在独立应用窗口运行时才显示已安装。不会自动安装或清理站点数据。

**本地数据核对**：安装不等于同步。更换浏览器或使用部分独立应用时，台账可能不共用；例如Mac Safari网页App与Safari网站数据分开。可先点卡片「备份台账」，导出完整JSON或完整台账Excel，安装后核对记录，必要时恢复备份；不要把空列表当成原数据已被删除。

官方依据（核验日期2026-11-04）：一次性安装提示及用户手势见[MDN prompt](https://developer.mozilla.org/en-US/docs/Web/API/BeforeInstallPromptEvent/prompt)、[web.dev安装交互](https://web.dev/articles/customize-install)；移动与桌面支持差异见[MDN可安装PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)；具体系统步骤见[Apple iPhone](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)、[Apple Mac与网站数据隔离](https://support.apple.com/en-nz/104996)。

## 管理页怎么用

管理页底部显示版本卡，也可进入 **管理 → 版本与更新**。

| 显示或操作 | 含义 |
| --- | --- |
| 当前运行版本 | 这次页面实际加载的版本，来自页面构建内容，不根据线上返回值改写 |
| 线上最新版本 | 本次成功联网读取的发布版本；完整构建号相等才确认一致 |
| 上次查到的版本 | 上一次成功读取的参考信息，不能证明现在仍是最新 |
| 检查最新版本 | 绕过浏览器缓存读取固定发布信息；不会主动刷新页面 |
| 更新并刷新 | 下载并启用线上对应资源，再刷新本页；回来后核对实际运行构建号 |
| 刷新并校验 | 已是最新时也可以显式刷新，并查看“刷新完成”的校验回执 |
| 强制更新到最新版本 | 重新联网核对版本、绕过旧更新脚本缓存准备资源，并完成接管与刷新验证 |

检查显示明确时间。离线、网络失败、错误响应或发布中资源不一致时，会显示无法确认或更新未完成，不会把“没检查到”当作已经最新。可以联网后重试。

## 更新前后

先保存正在编辑的内容，再点击更新。刷新会清空尚未保存的表单和沙盒；已经保存的交易、回补成交、股票配置、凭据及操作历史保留。更新只操作应用资源，不删除IndexedDB、不清空站点数据，也不注销同域其他应用的Service Worker。

打开多个页面时，手动更新可以主动启用等待中的新版，不必反复刷新或关闭所有窗口。其他页面不会被代码强制刷新；请保存各页面内容后自行刷新。更新后的本页显示“更新成功”或“刷新完成”，并联网核对是否与当前发布一致。若刷新后仍不是目标构建号，明确提示重试，不自动循环刷新。

2026-11-04的价位累计盈利与下一轮奖励新增实际费用归属字段。启用新版后，请先刷新其它已打开的本站标签页或主屏幕窗口，再继续记成交；旧页面不认识这份新元数据。程序不会强制刷新其它窗口或丢弃未保存草稿。

首次从没有此功能的旧版本升级时，旧页面自身没有新按钮。请先保存内容，关闭本站全部标签页和主屏幕窗口后重新打开一次；看到版本入口后，以后的更新直接在入口完成，不需要清理站点数据。

## 页面暂时无法打开

页面资源下载失败或页面显示发生异常时，会显示「页面暂时无法打开」，底部导航继续可用。检查网络后可点「重试当前页面」，也可以进入「版本与更新」核对版本，或返回管理页。

提示中的「备份台账」直接读取本机已保存数据并生成JSON文件，不必先打开失败页面。请核对浏览器下载记录；导出失败会提示重试。程序不会因为页面报错自动刷新、清理站点数据或删除交易。

此入口处理页面加载与显示异常；保存操作的业务校验仍在原操作处显示。重试会重新打开当前页面，尚未保存的表单内容可能需要重新填写。

## 固定比较机制

每次生产构建同时生成页面内的版本信息与站点根目录的 `version.json`。构建号来自规范化源码内容的SHA-256摘要；相同源码、路径与构建模式重复构建得到相同构建号。时间、提交号仅供追溯，不用时间先后猜新旧；线上实际发布的构建号是本次更新目标，回滚发布也可正确切换。

`version.json`不进入离线预缓存。每次检查使用独立查询参数与 `cache: no-store`；响应必须符合当前应用、路径与协议。正式资源和更新脚本也携带构建身份，必须等目标资源完整安装并接管后才刷新；刷新回执再次对照页面编译内的构建号，不能仅因调用刷新成功就声称更新完成。

开发环境使用即时热更新，显示“本地开发版”，不假装检查线上生产版本。

## 维护与验证

### 手机桌面图标

安卓安装读取manifest中的192/512像素图标；可裁切图标单独使用 `pwa-maskable-512.png`，留出安全边距。iPhone/iPad通过 `apple-touch-icon.png`（180像素、不透明）添加到主屏幕。图标链接使用应用base，兼容GitHub Pages的 `/EzGridApp/` 子路径，图标资源随Service Worker预缓存。

图标原图保存在 `assets/pwa-icon-source.png`。替换原图后运行 `node scripts/gen-pwa-icons.mjs`，再构建发布。该脚本仅缩放及补安全边距，不重新绘制图案。

手机浏览器打开网站后，安卓通过菜单「安装应用／添加到主屏幕」，iPhone通过Safari分享菜单「添加到主屏幕」。已经安装的桌面图标由系统缓存，应用更新后可能不会立即换图；仍显示旧图时，可从浏览器为当前网站重新添加主屏幕快捷方式。不要清空站点数据或删除交易库来换图标。

版本构建：`scripts/buildVersion.ts`；客户端检查与接管：`src/ui/appUpdate.ts`；管理页：`src/pages/manage/ManageUpdates.tsx`。后续发布必须同时上传整个 `dist/`，包含版本文件与对应资源。

运行 `node e2e/updates.mjs`。测试会构建A、B两个真实生产包，在独立临时浏览器中保持旧标签打开，切换服务器发布后验证检查、单次更新、强制刷新、失败与离线状态，以及数据保留；覆盖 `/EzGridApp/` 子路径和320像素界面。它不操作用户平时的浏览器台账。

页面异常回归：`node e2e/errorRecovery.mjs http://127.0.0.1:5173`。独立profile故障注入覆盖主页面及嵌套指南下载失败、渲染异常、用户重试、直接JSON备份、保留导航及320像素布局；不在产品代码中添加故障开关。

发布门槛由 `.github/workflows/quality.yml`统一定义：PR检查及main部署运行单测、lint、GitHub Pages子路径构建、核心账务/导入/数据一致性/页面异常浏览器专项。部署工作流只使用该轮通过检查的`checked-dist`产物；浏览器失败诊断留作CI附件。正式构建检出至少5条提交供更新说明读取。工作流配置完成不代表未经推送的本地修改已经上线。

安装回归：`appInstall.spec.ts`验证一次性事件、取消/失败、并发及实际安装确认；`node e2e/pwaInstall.mjs http://127.0.0.1:5173`验证真实管理页面、跨页早到事件、不同设备指引和320/390像素布局。自动化使用可控安装事件，不代替iPhone真机或系统安装窗口验收。生产构建继续核对manifest图标、启动路径、作用域和Service Worker资源。
