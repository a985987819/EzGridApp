# 完整台账 Excel：导出、编辑与恢复

管理 → **备份**以及明细页的「完整台账 Excel（可恢复）」会导出全部记录和关联，不受当前筛选影响。文件可用于换设备、备份，以及在 Excel 中查看回本链并编辑原始数据。明细 Excel/CSV 只导出当前筛选供查看，不携带完整关系；文件带用途标记，导入器会拦截，防止丢关联或重复记账。录入新交易仍可下载空白模板。

## 恢复步骤

1. 在管理页导出完整台账，保留一份原文件。
2. 需要调整时，在副本中编辑数据或人工关联。
3. 选择「从完整 Excel 恢复（先预览）」，也可以在普通导入入口选该文件，系统会自动识别。
4. 核对记录数、成交数、盈利和待买待卖量。系统重新计算所有自动关联、回本链和组池奖励，与导出时的核对表比较；变化会列出具体字段的前后值，每表最多展示 12 项。
5. 若需完整检查，点「下载重算核对表」，查看重新计算后的全部结果。
6. 点「确认整库替换并恢复」。系统先下载当前数据的 JSON 快照，再用一个事务替换台账；失败时不会留下半包数据。

这是**全量恢复**，不与当前台账增量合并。恢复同一文件多次不会重复增加记录。原来的普通模板、CSV 增量导入和 JSON 备份继续可用。

## 工作表与关联

| 工作表 | 用途与编辑规则 |
| --- | --- |
| 台账说明 | 文件格式、计算口径版本、导出时间和「推定已成交售价」设置；其余行是说明 |
| 交易数据 | 原始交易及软删除、编辑时间、录入批次；买入、卖出、回补价可编辑 |
| 股票设置 | 股票、默认间隔、涨跌幅、排序、启用状态 |
| 回补成交 | 每笔实际回补成交与奖励份额；虚拟回补批次由这些成交重建，不作为交易重复导入 |
| 成交回执 | 一次操作的永久编号、实际成交、记录/回补分配、凭据与核对/撤销状态。只读保留，不复制回执制造另一笔成交；旧完整文件没有此表仍可恢复 |
| 人工高位关联 / 人工高位分配 | 前者每条关联一行；后者按关联 ID 填高位买单及分配股数。保留没有分配子项的父行，表示明确禁止自动挂钩；删除父行和其所有子项，表示恢复自动选择 |
| 人工回本链 / 人工链成员 | 保存人工归属、锚点、结束时间；每个成员只能进入一条人工链。没有成员的父行仍可保留结束状态 |
| 批次合并 / 合并成员 | 保存人工合并组、成员和旧计划引用 |
| 挂单计划 / 买单拆卖 / 卖单拆买 | 保留改单价量与分档。挂单计划仍只影响建议显示与成交默认值，不改变实际盈亏 |
| 导入批次 / 操作历史 | 保留录入历史和审计；建议只读 |
| 核对_高位关联 | 展示所有生效的高位关联及「自动 / 人工」来源 |
| 核对_回本链 / 核对_链分支 / 核对_链成员 | 展示原始亏损、后续盈利、实际累计盈亏、剩余回本差额，以及每笔交易所属的链 |
| 其他核对_工作表 | 记录序号、合计、批次、卖出、待买待卖、买入建议和来源、卖出挂单、组池奖励 |

**核对_ 开头的表只读**，是导出时的快照，Excel 内不计算业务逻辑。恢复时它们不写入数据库，自动高位关联和自动归链会重新生成，绝不会被固化成人工关联。修改这些表只会影响差异提示，不会修改真实账务。

## 固定身份与单位

- **记录 ID**是内部永久主键（原 `sourceRow`），不是工作表物理行号，也不是界面「第 N 笔」。排序、移动行或调整工作表顺序都不会改变关联。
- 关联 ID、成交 ID、批次 ID、原始身份键和「原始顺序（勿改）」应保持不变。原始顺序用于还原同时间发生的事件顺序；界面序号仍按原始批次与录入时间推导，软删除记录也占号。
- 价格、金额全部是**整数分**：8.01 元填 `801`；股数是整数；日期列使用 Excel 1900 日期序列值；时间戳使用 Unix 毫秒。
- 布尔值只接受 Excel 的 `TRUE` / `FALSE`。不接受公式及公式缓存结果，请填写确定的值。
- 必填列不许空。可缺省字段留空表示未设置；`〈null〉` 保留显式 null，`〈空字符串〉` 保留空文本。导出器会转义恰好使用这些特殊标记的普通文本。
- 交易软删除使用「软删除时间戳」。物理删除一笔数据时，必须同步删除或修改所有引用，否则整包拒绝。

## 校验与边界

缺工作表或列、重复主键、非法金额股数、未来版本、悬空引用、不同股票间的人工关联、重复人工归链及批次依赖环都会拒绝导入，并给出工作表与记录定位。发现完整台账的标记后，缺说明表也不会退回普通导入，以免静默丢失关系。

编辑合法数据会使核对结果发生变化，这是允许的；预览显示差异后可确认恢复。检查通过只说明文件结构、引用和快照比较通过，现有业务异常仍按台账规则显示。

包含：交易及软删除历史、股票配置、计算设置、回补成交、人工关系、拆单和计划、批次与操作历史。
不包含：沙盒草稿、页面筛选/展开状态、系统字体、行情昨收与手工涨跌停区间（沿用既有规则，不属于账务备份）。完整台账恢复后仍需核对当天行情再挂单。

格式版本为 `1`，计算口径版本为 `2`，底层备份结构仍为 `schemaVersion: 11`。新增可选「卖出来源档ID」（交易数据）与「买入来源档ID」（回补成交），保留改单前的实际来源；删掉原档后这些字段仍作为成交历史保存。价格与数量可调整，来源身份不要手改。

兼容计算口径 `1` 的旧完整文件及旧 JSON：没有来源身份的历史成交按同价档匹配，买入价格不匹配的余量按档位顺序分配。旧文件按修正后的拆单逻辑重算，核对差异会在恢复预览中列出。无法从旧记录推知的改单前来源不会凭空补写，必要时先核对分档。
