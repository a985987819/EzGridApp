## 一、字体语料子集化（P0，已执行）

- **问题**：animal-island-ui 自带 Noto Sans SC 中文 400/700 两个整字体共 2.26MB（无 unicode-range），占预缓存一半；V9.60 已剥 500 字重。
- **方案**：`scripts/subsetFonts.mjs` 扫描 `src/**/*.{ts,tsx,css}` + `docs/*.md` + index.html 的实际用字（去重 1,389 字符）作语料，用 `subset-font`（harfbuzzjs，纯 Node）生成子集，产物 `src/assets/fonts/noto-sans-sc-{400,700}-subset.woff2` **入库**（~180KB/档）。`npm run subset-fonts` 重新生成。
- vite 插件 `stripChineseFontFaces`（原 stripChineseFont500 扩展）：把库 CSS 里 Noto Sans SC 的中文 400/500/700 **与 latin 400/500/700** @font-face 全部剥离——latin 小档与子集同族同字重且都没有 unicode-range，谁后拼进 bundle 谁通吃，必须只留子集唯一声明（ASCII 已在子集语料里；Nunito 继续管 ASCII 首选）。
- styles.css 顶部自声明两个 @font-face（'Noto Sans SC' 400/700，font-display swap）。
- **缺字兜底**：语料外的新字（新股票名/备注里的生僻字）由字体栈后面的 PingFang SC/微软雅黑自动渲染，观感略不同不缺字；另有管理 → 备份的「使用系统字体」开关整体切走（`applySystemFont`，useApp.tsx）。
- **维护**：新增含新汉字的文案/文档后重跑 `npm run subset-fonts`（忘了不致命，只是新字回退系统字体）；升级 animal-island-ui 后若脚本报 404，按提示更新脚本里的字体文件 hash 后缀。

## 二、页面级 React.lazy 拆包（P1，已执行）

- App.tsx 五个页面（概览/明细/挂单/统计/管理）改 `lazy(() => import(...))` + `PageSuspense`（`<div className="empty-box">正在打开…</div>`，复用现有空态样式）。TreeTrunk 随 Overview chunk 自动分出。
- index 410→145KB；页面 chunk：Orders 54KB / Trades 45KB / Overview 39KB / Manage 35KB / Stats 14KB（另有共享小 chunk）。PWA 预缓存收全部 chunk（37 项），离线切页无等待；Suspense 兜底只在未缓存首次进入时闪现。
- vendor-react 空壳条目从 manualChunks 删除（react 物理上在 vendor-ui 内，该条目只剩 33B re-export 死 chunk 还被预缓存）。

## 三、价格树 TreeTrunk 三项（P1，已执行）

- **数据更新保视角**：levels 原在主 effect deps 里——台账任何写入都派生新数组 → 整树重挂（canvas/监听/ResizeObserver 全部重建）且 pan/zoom 视角重置。现在 levels/effYear 走 ref（`levelsRef/effYearRef`），数据更新只 `bumpCanvas` 标脏一帧；派生列表与价格区间进 `dataCache`（按 levels identity 缓存）；effect deps 收窄为 `[stockName, style, effYear]`（换股/换风格/换年份本来就是显式动作，保留重置）。
- **每帧缓存**：groupLevels 合并分档按（levels, gap）缓存进 `groupCache`——pan 不动 span 时整帧复用；数轴风两个 createLinearGradient（背景/轴线）按 (ctx, H) 模块级缓存，换画布或改尺寸才重建（treeStyleAxis.ts）。
- **沸腾 reduced-motion**：手绘风交互后的 ~140ms 沸腾窗口加 `matchMedia('(prefers-reduced-motion: reduce)')` 检查，reduced-motion 用户静帧呈现。
- 回归：smoke 树断言（bins/zoom/pickAt/ideal/year）全量通过；e2e 桥 `__tree.levels()/year()` 改读 ref，行为不变。

## 五、版本更新说明（P0，已执行）

- `scripts/buildVersion.ts` 构建时读 `git log -5 --pretty=%s` 写入 `version.json.releaseNotes`（可选字段，无 Git 构建留空；schema 仍为 1，旧文件兼容）。
- 管理 → 版本与更新：有新版且线上版本带 releaseNotes 时列出（`[data-testid="release-notes"]`）。
- **红线不变**：仍是 prompt 模式 + 手动刷新生效；不做 autoUpdate/后台强制重载/清空数据；updates.mjs 全部既有钉通过。

## 六、评估后不做 / 调整的项目

- **操作指南文档按篇拆 chunk（P1，评估后不做）**：指南的搜索是**全文匹配**（ManageGuide 里 `matches(...d.body...)`），摘要/下载/目录也都依赖同步 body；按篇拆 chunk 必须把搜索、下载、深链全部改异步，首开流程复杂化、e2e 有竞态风险，而收益只剩「发版改文档时的更新粒度」（文档变更频率低，且 ManageGuide 本就是懒 chunk）。保持现状；页面拆包已把 index 里的文档压力解掉。
- buildLedger / currentLedger 增量化：62 行规模收益≈0，触碰记账正确性红线。
- useApp Context 拆分、TradeItem memo、OrdersPage 挂钩查找 Map 化、useKeyboardInset rAF 节流：当前数据规模无感，**触发条件 = 行数 >500 或低端机实测卡顿**，届时按此清单执行。
- unicode-range 字体分片：PWA 全量预缓存下总字节不变，无收益。
- SVG 装饰图压缩（4 张 315KB）：可选，未执行。
- xlsx 静态化、autoUpdate、后台强制重载、清空数据更新：红线，永远不做。
