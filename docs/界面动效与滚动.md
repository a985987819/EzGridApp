# 界面动效与滚动

更新：2026-10-29。仅调整界面交互，不涉及交易口径与数据库结构。

## 按钮与统计页布局

全站按钮统一使用下沿实心阴影：普通4px、鼠标悬停5px、按下1px、禁用2px；组件库的文字/链接按钮、自定义筛选、导航、管理入口和弹层按钮共用同一规则。危险操作保留红色阴影，选中、禁用、键盘焦点和减少动态效果分别保留。阴影规则集中在 `src/styles.css`，不要在单个页面另加平面按钮例外。

统计页按“成交日历 → 月度成交 → 买卖与盈利汇总 → 网格进行度 → 高成交点位 → 趋势及其他统计”排列；只移动原有模块，数字及深链口径不变。手机日历将年月与翻月操作分行，避免窄屏文字折成竖排。

## 卡顿与闪烁的原因

明细和挂单页原先在滚动到阈值时，切换 React 状态，并用 `grid-template-rows`、padding 连续压缩整个吸顶设置区。收放期间文档高度不断改变，下方所有台账内容随之移动。每次过渡都需要多次布局计算；滚动与布局位移叠加时容易出现抖动。旧版本还叠加了整页、模块、逐行及指标的入场动画，放大了闪烁感。

## 当前交互

| 场景 | 行为 |
| --- | --- |
| 底部导航、跨页跳转 | 按导航顺序提供方向一致的离场和入场；切页时在快照更新中回顶，避免旧页先跳到顶部 |
| 快速连续切页 | 跳过上一段动画并提交对应动作，最终落在最后点击的页面 |
| 切股票、明细筛选与排序、管理子页、沙盒切换 | 内容淡入淡出；输入文本本身保持即时响应 |
| 滚动明细/挂单 | 完整设置自然滚出，顶部留下单行摘要；点击摘要平滑回顶 |
| 模块滚入 | 在进入视口前 64px 准备一次短淡入与 10px 位移；已展示的模块不再次隐藏 |
| 原生 details | 主动展开/收起时进行 220ms 高度过渡；快速反向操作从当前高度接续，结束后恢复自然高度 |
| 编辑弹层 | 沿用现有保滚动机制；body 固定期间不误判为回到顶部 |
| 系统减少动态效果 | 页面、滚入、摘要与 details 瞬切；回顶不使用平滑滚动 |

## 实现边界

- `src/ui/scrollHeader.ts` 通过 `ResizeObserver` 在尺寸变化时测量摘要高度。滚动监听为 passive，以 rAF 合并，只在状态跨越阈值时更新 DOM 标记，不触发页面 React 重渲染。
- 完整设置保留原文档高度，使用负 sticky top 随原生滚动移出视口。摘要绝对定位在容器底部，收放只改变透明度和小幅位移；稳定底色避免内容透入摘要。
- 摘要和完整设置互斥使用 `inert` / `aria-hidden`，隐藏控件不会进入键盘焦点。设置内仍有焦点时不主动将其设为 inert。
- `src/ui/transitions.ts` 使用浏览器 View Transition，React 更新通过 `flushSync` 在快照回调内提交。底部导航单独保留，不随整页滑动。浏览器不支持时退化为即时更新与短淡入；后台页面不等待快照。
- `src/ui/pageMotion.ts` 使用单个 `IntersectionObserver` 展示模块，监听新增模块，页面切换时清理。首屏由页面过渡负责，避免多层入场重叠；逐行和逐指标的批量动画已移除。
- 高度过渡仅用于用户主动展开的 details 和现有删除行。不要给滚动状态增加高度动画，也不要为所有列表行永久加 `will-change`。
- 原生 details 的 `open` 属性、键盘触发和程序化展开继续可用。未运行 JS 时内容不由默认 CSS 隐藏。

## 性能采样

本机无头 Chrome，390×844，真实 62 行 XLSX fixture。相同脚本从页顶滚到 300px，采样约 800ms：

| 指标 | 明细改前 | 明细改后 | 挂单改前 | 挂单改后 |
| --- | ---: | ---: | ---: | ---: |
| 吸顶容器高度变化 | 82px | 0px | 139px | 0px |
| 文档高度变化 | 82px | 0px | 139px | 0px |
| 下方内容的文档坐标位移 | 82px | 0px | 139px | 0px |
| Chrome LayoutCount 增量 | 27 | 2 | 29 | 4 |

这些数字是该样本的一次对比，不代表所有设备的帧率。回归重点是收放期间文档与下方内容坐标稳定，以及往返滚动不反复切换摘要状态。

## 验收

先启动 `npm run dev`，再运行：

```bash
node e2e/motion.mjs http://127.0.0.1:5173
node e2e/smoke.mjs http://127.0.0.1:5173
node e2e/accounting.mjs http://127.0.0.1:5173
```

`motion.mjs` 使用独立临时浏览器，导入真实 fixture，检查文档稳定性、摘要可见性及焦点隔离、往返滚动、回顶、折叠反向、模块只展示一次、快速连切、弹层保滚动、减少动态效果、不支持 View Transition 时的降级、窗口缩放、键盘展开及运行时错误。截图与采样结果输出到被 Git 忽略的 `e2e/out/motion/`。

`smoke.mjs` 的顶部收放断言以「摘要可见、控件隐藏、占位不变」为准；不要恢复成「容器高度必须缩小」。后者会重新引入卡顿来源。

本次验证：372 条单元测试、477 项界面检查、42 项动效检查、真实 IndexedDB 成交回归、Lint 和生产构建全部通过。

仍需在实际手机上确认触摸惯性滚动、浏览器地址栏伸缩和不同安全区的观感；自动化采样不代替真机体验。
