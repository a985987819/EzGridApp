# 规划用钱

更新：2026-11-03。

管理页的【规划用钱】分区回答「这笔可用资金现在买哪只、能买多少、值不值博」：输入当前可用资金，页面列出**全部启用股票**的温度带、现价、整手可买股数与值博率，并按值博率从高到低排序。纯参考页——不进台账、不参与任何账务计算、不写挂单。

## 资金与现价

- **当前可用资金**：只存本机浏览器（localStorage `ezgrid.moneyPlan`），不进台账、不进备份，换设备要重填；清空输入即清除记忆。
- **现价** = 挂单页已确认的昨收；未确认时回退估值快照最后收盘，卡片右上角会标注来源（昨收 / 快照收盘）。
- 在本页改价等于「确认昨收」：点「更新昨收」写的是挂单页同一个会话（`ordersSession.confirmedCents`），挂单页买入推荐、涨跌幅区间、概览温度带同步生效。

## 可买股数

- 按整手计算：`可买股数 = floor(可用资金 ÷ 现价 ÷ 100) × 100`（A 股主板一手 100 股），同时给出所需金额与剩余金额；资金不足一手显示 0 股，**不凑零股**。
- 「这笔钱全买它」的口径——多只股票之间怎么分配由你决定，页面用值博率排序给参考。

## 值博率口径

```
值博率 =（5 年中位价 P50 − 现价）÷（现价 − 5 年 P20 价）
```

- **上看 5 年中位**（均值回归目标）、**下破 P20 认错**（止损参考线）；≥2 值博（绿）、1–2 一般（黄）、<1 偏低（红）。
- 现价 **≤ P20**：分母趋零、比率失真，直接标「优 · 已到 P20 下方」（排序最优先，同档按股价百分位从冷到暖）。
- 现价 **≥ 中位**：已无「向中位回归」的空间，标「低 · 已在中位上方」（排序靠后）。
- 每张卡同时给出三个锚点价：中位（上看）、P20（下看）、P80（强势目标参考）。
- **边界**：值博率只回答「位置上的赔率」，不预测方向、不构成买卖指令；亏损股 PE 失效时看股价与 PB 温度带；网格买卖仍以挂单页档位为准。

## 排序与数据

- 排序：已低于 P20 → 比率 ≥2 → 1–2 → <1 → 已过中位 → 无估值数据；同级内更冷/比率更高在前。
- 温度带与锚点价来自静态估值快照（同概览温度带，`npm run refresh-valuation` 刷新，除权后必须）；锚点按快照窗口内全部收盘价取分位数。
- 界面位置：管理 → 规划用钱（`#/manage?section=money`，`[data-testid="manage-money"]`）；每卡 `[data-money-stock="股票名"]`，可买行 `[data-money-plan]`。
